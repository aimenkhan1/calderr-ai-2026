# 🤖 Nova — Agentic Research Assistant

An AI-powered research assistant that takes any question, plans a research
strategy, makes sequential LLM calls to explore subtopics, and produces
a structured report with confidence scores — all in a beautiful purple chat UI.

---

## 📸 What It Does

Type any research question and Nova will:

- 🧠 **Plan** — Break your question into 3 focused subtopics
- 🔍 **Research** — Make 3-5 sequential Groq API calls to explore each subtopic
- 📄 **Report** — Synthesize all findings into a structured report with confidence scores
- 💬 **Chat** — Keep the conversation going like GPT with full session history
- 📥 **Download** — Export your research report as a text file
- 📜 **History** — View, revisit, and delete past research sessions

## 🏗 Architecture

```
Question Input
      ↓
Validator          → checks if question is valid research topic
      ↓
Planner Agent      → breaks question into 3 subtopics (Groq call 1)
      ↓
Research Loop      → researches each subtopic (Groq calls 2-4)
      ↓
Synthesis Agent    → combines all findings (Groq call 5)
      ↓
Report Formatter   → structures with confidence scores and sources
      ↓
Streamlit UI       → chat interface with progress bar and download
```

## 🚀 Setup & Run

### 1. Clone the repository
```bash
git clone https://github.com/aimenkhan1/calderr-ai-2026.git
cd calderr-ai-2026/projects/week1-research-assistant
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Add your API key

Create a `.env` file in the project root:
```
GROQ_API_KEY=your_groq_api_key_here
```

Get your free key at console.groq.com

### 4. Run the app
```bash
streamlit run main.py
```

The app opens at http://localhost:8501

## 📝 Notes

- History is stored in Streamlit session state — cleared on page refresh
- Each research session makes 5 Groq API calls total
